🎬 PSO2 Animation Viewer

Preview any in-game animation (Emotes & Motions) in 3D and swap them directly into your game.

Download Program

How to Use

1
Load a test model: In the top panel, click M1 or M2 to load a default 3D mannequin.
2
Link your game data directory: Click pso2 data… and select your game's pso2_bin/data/win32 folder (or win32reboot). This allows the viewer to extract and display weapons, props, and VFX in real time.
3
Search and preview animations: Filter by Emotes or Motions, and search by English name, Japanese name, or chat command (e.g. /sivapose1). If an emote has multiple hand poses or click stages, press the HSI / CLICK button to cycle through variants.
4
Swap animations in-game: Switch to the Replace tab. Under 1) ORIGINAL, select the base animation you own in-game (e.g. Sit 1). Under 2) NEW, choose the animation you want to see. Click Apply to Game. An automatic backup is created in ./portable/backups so you can revert anytime with 1 click.
💡 Built-in Mod Manager: You can install mods from .zip archives in the Mods tab and toggle them on/off. It automatically resolves conflicts by deactivating older mods modifying the same animation.

Live 3D viewport playback and in-game animation replacement demo.

👗 CMX Helper Tool

Enables jackets over outfits that normally don't support them, and toggles hidden ornamentation layers.

Download Program

How to Use

1
Open the tool alongside your game or the Animation Viewer.
2
Enable Outerwear (Jackets): Turn Allow Outerwear: ON to allow equipping outer jackets over base costumes in the Salon that are locked by default.
3
Hide Ornamentation: Turn on Hide Ornament 1 or Hide Ornament 2 to hide specific clothing ornaments or stage parts in the Salon.

1. Enable outer jackets over base costumes in Salon.

2. Toggle and hide clothing ornamentation parts.

🎙️ PSO2 Voice Modifier

Customize and replace in-game character voices with your own custom audio tracks (MP3, OGG, WAV).

Download Program
⚠️ Important Requirement: This program must always be run from inside your game's pso2_bin directory.

How to Use

1
Select Audio Language: If playing Global with English audio, select EN (win32na). If playing with Japanese audio, select jp (Win32). (Native Japanese server players do not need to press language buttons).
2
Select Voice to Modify: Pick the target character voice from the list.
3
Add Your Audio Tracks: Assign your custom audio files in MP3, OGG, or WAV format.
4
Save Voice Presets: You can export and save your customized voice packs to reuse them on other character voices anytime.

Live voice replacement in-game demonstration.

1. Voice selection and language assignment panel.

2. Save and load custom audio presets.
