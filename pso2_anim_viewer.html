🚀 1. Initial Setup (Linking with Game Data)

The program is 100% portable and requires no installation. You can run it from any folder or USB drive.

📥 Download Pso2AnimViewer.zip
👤 Load 3D Base Model:

In the top MODEL panel, click M1 or M2 to load a default mannequin test model.

📁 Link Game Data Directory (pso2 data...):
  • In the GAME DATA panel, click pso2 data….
  • Select the data folder from your PSO2 NGS installation.
  • Typical path:
    .../PHANTASYSTARONLINE2_NGS/pso2_bin/data/win32
    (or win32reboot)
💡 Why is this needed?
This allows the viewer to extract and display weapons, props, visual effects (VFX), and accessories in real-time.

🔍 2. Searching & Filtering Animations

In the left ANIMATIONS panel:

🏷️ Filter by Type:
  • All: Shows the complete catalog (Motions + Emotes).
  • Emotes: Lobby Actions and dances.
  • Motions: NGS Substitute Motions (Standby, Dash, Glide, Run, Jump, Landing, Swim).
♀️♂️ Gender Filter for Emotes (Emote F/M):
  • F: Shows Female emote variants (equivalent to /fla commands in-game).
  • M: Shows Male emote variants (equivalent to /mla commands in-game).
  • Both: Shows all variants.
🔎 Search Bar:

You can search by:

  • English name: (e.g., Shiva Pose 1, On the Phone)
  • Japanese name: (e.g., シバポーズ1, スマートフォン)
  • Chat command with slash: (e.g., /sivapose1, /smartphone)

▶️ 3. Playback & Interactive Multi-Stage Poses (HSI / CLICK Button)

Click any animation row in the list to preview it in the 3D viewport.

⚡ Interactive Multi-Stage Click Emotes (HSI):
  • Many emotes (On the Phone, Shiva Pose 1, Sparkler, etc.) have multiple hand poses or click stages (e.g., stage 1/3).
  • Upon loading a multi-stage emote, the top toolbar will display its stage count (e.g., stage 1/3).
  • To advance to the next pose or hand variant, click the HSI / CLICK button on the top toolbar (or the HSI button on the playback bar).
  • Each click advances the animation and updates attached props/weapons in real time, matching in-game action key behavior.
🎛️ Top Timeline Controls:
  • PLAY / Stop: Start or pause animation playback.
  • Loop ON/OFF: Enable or disable continuous looping.
  • Speed Slider (1x): Adjust playback speed.
  • Camera Controls: Left Mouse Button to rotate | Scroll Wheel to zoom | Middle Mouse Button / Ctrl+LMB to pan.

🔄 4. Swapping Animations In-Game (Replace Tab)

This feature allows you to replace an animation you own in-game with any other animation from the catalog.

1️⃣ Switch to the Replace tab on the left panel.
2️⃣ Step 1 - ORIGINAL (In-game slot):

Under 1) ORIGINAL, search and select the base emote/motion you want to replace (e.g., default emote Sit 1).

3️⃣ Step 2 - NEW (In-game content):

Under 2) NEW, search and select the new animation you want to see in-game (e.g., Shiva Pose 1 or a custom Motion).

4️⃣ Step 3 - Apply to Game:

Click Apply to Game (backup first).

The program writes the modification into game files and automatically creates a backup in ./portable/backups.

🎉 You're done!
Launch the game or type /sit1 to see your new animation.
🛡️ Restoring Backups

To revert modifications back to official game files:

On the Replace tab, click Restore last backup or Open backups to restore original files in 1 click.
